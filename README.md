# Поиск общих ключевых точек на изображениях планктона

Учебный проект по компьютерному зрению: поиск локальных особенностей организма, построение дескрипторов и сопоставление изображений с помощью **SIFT и OpenCV**.

## Структура проекта

| Файл | Назначение |
| :--- | :--- |
| [plankton_sift.ipynb](plankton_sift.ipynb) | Основной анализ: предобработка, SIFT, попарные совпадения и поиск общих точек |
| [sift_parameters.ipynb](sift_parameters.ipynb) | Исследование влияния параметров SIFT |
| [sift_robustness.ipynb](sift_robustness.ipynb) | Контрольные опыты с поворотом, масштабом, размытием и JPEG-сжатием |
| [requirements.txt](requirements.txt) | Зависимости Python |
| [PLANKTON/](PLANKTON/) | Исходные изображения |

## Запуск

Из папки проекта создайте окружение и установите зависимости:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

## Задание

**Цель:** определить ключевые точки, соответствующие одним и тем же локальным особенностям объекта на разных изображениях.

### Реализация

1. Найти ключевые точки и вычислить дескрипторы для каждого изображения. Допустимые методы: **SIFT, ORB, AKAZE, BRISK** или другой обоснованно выбранный метод.
2. Изучить и описать параметры выбранного метода.
3. Сопоставить дескрипторы и удалить ненадёжные совпадения.
4. Определить общие точки — те, для которых найдены соответствия **на всех рассматриваемых изображениях**.
5. Визуализировать общие точки одинаковыми обозначениями: точка №1 должна соответствовать точке №1 на остальных снимках и так далее.
6. Если общих точек много, показать **лучшие 30**. Расположить изображения рядом и сравнить положение точек.

### Анализ результатов

В выводах указать:

- число первоначально найденных ключевых точек на каждом изображении;
- число соответствий между изображениями;
- число точек, общих для всех изображений;
- части организма, на которых расположены наиболее устойчивые точки;
- устойчивость метода к изменению положения, масштаба, ориентации и качества изображения.
